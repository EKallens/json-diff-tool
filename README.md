# JSON Diff Tool 🧩

Una herramienta simple para comparar dos archivos JSON y ver sus diferencias.

## ✨ Características

- Pega o escribe dos JSONs lado a lado
- Compara claves nuevas, eliminadas o modificadas
- Muestra los cambios de forma clara
- Interfaz limpia con ShadCN y Tailwind

## 🚀 Tecnologías

- [React](https://reactjs.org/)
- [Vite](https://vitejs.dev/)
- [TypeScript](https://www.typescriptlang.org/)
- [TailwindCSS](https://tailwindcss.com/)
- [ShadCN UI](https://ui.shadcn.com/)

## 🛠️ Instalación

```bash
git clone https://github.com/EKallens/json-diff-tool.git
cd json-diff-tool
npm install
npm run dev
